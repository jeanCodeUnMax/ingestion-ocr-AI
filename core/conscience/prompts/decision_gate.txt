LES 10 QUESTIONS DÉCISIONNELLES

1. What changed? (Qu'est-ce qui a changé ?)
   → Y a-t-il un changement réel par rapport à l'état précédent ?

2. Is it relevant? (Est-ce pertinent ?)
   → Cet événement mérite-t-il une attention ?

3. Is it expected? (Est-ce attendu ?)
   → Fait partie du fonctionnement normal ?

4. Is it harmful? (Est-ce nuisible ?)
   → Y a-t-il un risque ou un impact négatif ?

5. Is it already known? (Est-ce déjà connu ?)
   → Ce pattern a-t-il déjà été observé ?

6. Can I explain it with enough confidence? (Peux-je l'expliquer avec confiance ?)
   → La compréhension est-elle suffisante ?

7. Am I allowed to act? (Suis-je autorisé à agir ?)
   → Les permissions permettent-elles une action ?

8. Is the action reversible? (L'action est-elle réversible ?)
   → Puis-je annuler si nécessaire ?

9. What is the lowest-risk useful action? (Quelle est l'action utile à moindre risque ?)
   → Identifier l'action optimale

10. Should I act now, defer, notify, or only memorize? (Agir maintenant, différer, notifier, ou mémoriser ?)
    → Décision finale

RÈGLES DE DÉCISION

Mode "act_now":
- harmful = true ET confidence_score >= 0.7
- reversible_action_available = true
- authorized_to_act = true

Mode "defer":
- relevant = true mais pas urgent
- confidence_score < 0.7
- Besoin de plus d'information

Mode "notify":
- harmful = true mais pas autorisé à agir
- Ou action non réversible nécessaire

Mode "memorize_only":
- relevant = false OU expected = true
- Pas d'impact significatif

RÈGLES STRICTES
- Réponds UNIQUEMENT en JSON valide
- Tous les champs booléens doivent être présents
- confidence_score entre 0.0 et 1.0
- decision_mode DOIT être: act_now, defer, notify, memorize_only
- requires_human_validation = true si harmful ET (pas réversible OU pas autorisé)
